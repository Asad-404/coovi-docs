## 🎯 Complete Project Specification

### Tech Stack
```
Backend:      Express.js + TypeScript + MongoDB + Mongoose
Storefront:   Next.js 16 + TypeScript + Tailwind CSS + Zustand
Admin Panel:  React 19 + Vite + TypeScript + Material UI
Database:     MongoDB Atlas (free M0 cluster)
Images:       Cloudinary (free tier)
Hosting:      Vercel (all 3 apps)
Tools:        Node.js 24 + pnpm + Git + MongoDB Compass
```

### Features (Your Confirmed Specs)
```
✅ Guest checkout (no user accounts)
✅ Manual product management via admin panel
✅ Cash on Delivery (COD) only
✅ Mobile-first responsive design
✅ Search by name (partial match, case-insensitive)
✅ Sort by price (ascending/descending)
✅ Infinite scroll with "Load More" button (12 products per batch)
✅ Shopping cart (Zustand + localStorage)
✅ 5 order statuses (Pending → Processing → Shipped → Delivered → Cancelled)
✅ Stock decreases on "Confirmed" status
✅ Delivery fee configurable in .env
✅ Prices in BDT (Bangladeshi Taka), displayed as whole numbers
✅ Product images 2:3 ratio (like Diponty)
✅ Size field optional (can be empty)
✅ Category field (all "Saree" initially)
✅ English language (Bangla later)
✅ Design inspired by Diponty.com
✅ Development (detailed errors) + Production (clean errors) modes
```
